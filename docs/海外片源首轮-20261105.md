## 入池与实现

新增4条候选（3条 YouTube、1条 X），均写入原发链接、核查说明和可见热度；候选池由436至440，已上架仍32。CHUMBO为待核线索而非已通过正片。本轮未生成封面、未转换作品、未发布。

- 作品存储、候选初筛、公开页面校验允许 YouTube 与 X／Twitter 的精确域名；伪造子域名仍拒绝。
- 修复旧去重规则忽略 query 导致所有 YouTube `/watch` 视频被认作同一作品的问题。按大小写敏感的视频 ID 判重，短链与带跟踪参数的长链归一；X／Twitter按帖子 ID 归一。国内来源旧规则保留。
- 首页来源筛选、片库来源显示／筛选、个人页名称与浏览器／服务端观看记录同步支持新来源，相关脚本缓存版本已更新。
- CLI 对海外来源明确提示“需浏览器核对，未自动验证”，不把未实现的自动扫描说成已接入，也不武断声称所有海外页面都必须登录。
- 沿用既有架构，无新采集依赖。参考开源 [bilibili-API-collect](https://github.com/bilibili-plugins/bilibili-api-collect) 的平台元数据思路与上述作者原站，未复制上游源码。
